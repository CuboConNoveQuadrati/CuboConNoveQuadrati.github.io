🚩 Goal: Decrypt the flag produced by a Hill-cipher-like scheme over mod 257.

🔍 Initial Exploration

The description hinted at a structured Hill cipher. The modulus 257 suggests arithmetic over a prime field, making matrix inversion feasible. The presence of an encryption oracle enabled a classic known-plaintext (more precisely, chosen-plaintext) attack.

🕵️ First Observations:

  • Key structure: K = P · L · U (mod 257) (product of matrices mod 257).
  • Oracle lets us encrypt arbitrary plaintexts and retrieve the flag ciphertext.
  • Over a prime modulus, any full-rank square matrix is invertible.

Plan: query with unit vectors to recover columns of the encryption matrix, then invert it to decrypt the flag.

🛠️ Investigation Process

📖 Step 1: Confirm the model

The server implements a Hill-like cipher over GF(257). If y = K · x (mod 257), then encrypting a unit vector e_i returns column i of K. Repeating this for all i reconstructs K entirely.

Key idea: chosen-plaintext with unit vectors recovers the full linear transformation in exactly n queries for an n×n system.

🧪 Step 2: Automate queries and collect columns

Using the solver, we connect, request the encrypted flag, and then loop over unit vectors to fill the columns of K.

from pwn import remote, context
import sys, os

n = 257
HOST = "a8abb4bb.ctf.ac.upt.ro"
PORT = 9603

class Connection:
    def __enter__(self):
        self.io = remote(HOST, PORT)
        return self
    def encrypted_flag(self):
        self.io.sendlineafter(b"> ", b"1")
        return self.io.recvlines(2)[-1].decode()
    def send_plaintext(self, data: bytes):
        self.io.sendlineafter(b"> ", b"2")
        self.io.sendafter(b"> ", data)
        return self.io.recvlines(2)[-1].decode()
    def __exit__(self, *args):
        self.io.close()

# Parse the server's hex numbers into integers
parse = lambda s: [int(x, 16) for x in s.split()]

with Connection() as conn:
    enc_flag = parse(conn.encrypted_flag())

# Recover K column-by-column using unit vectors
key = [[0]*n for _ in range(n)]
for i in range(n):
    plain = bytearray(n); plain[i] = 1
    with Connection() as conn:
        col = parse(conn.send_plaintext(bytes(plain)))
    for r, v in enumerate(col):
        key[r][i] = v

🧮 Step 3: Invert the matrix modulo 257

After converting to a Sage matrix over integers and reducing mod 257, we compute K^{-1} with modular arithmetic and apply it to the encrypted flag vector.

# In Sage / Python-with-Sage
key_matrix = matrix(ZZ, key) % n
# Invert via adjugate/determinant or built-in inverse over modular ring
# (Sage: key_matrix.inverse() works over QQ; we reduce properly mod 257)

def matrix_mod_inv(M, p):
    det = int(round(M.det())) % p
    det_inv = pow(det, p-2, p)  # Fermat (p prime)
    Minv = M.inverse()          # over QQ
    adj = (det * Minv) % p
    return (det_inv * adj) % p

K_inv = matrix_mod_inv(key_matrix, n)
flag_vec = vector(ZZ, enc_flag)
dec_vec = (K_inv * flag_vec) % n
flag = bytes(dec_vec).rstrip(b"\x00").decode()
print(flag)

Gotcha: ensure K is full-rank mod 257. Any I/O desync or wrong length breaks column recovery and makes the matrix singular.

🎯 Step 4: Decrypt the flag

With K^{-1} computed, multiplying by the ciphertext vector yields the plaintext bytes. Trimming padding zeros reveals the flag.

🧠 Technical Insights

  • Linear oracle extraction: Chosen-plaintext unit vectors recover linear maps with one query per dimension.
  • Prime modulus perks: Working in GF(257) simplifies inversion with Fermat’s little theorem.
  • Numerical care: Compute determinants/inverses over rationals, then reduce mod p consistently.

Performance note: 257 queries for columns + 1 for the flag is well within typical CTF rate limits.

🎯 Key Takeaways

  • Structured Hill ciphers are vulnerable to chosen-plaintext attacks.
  • Always operate modulo a prime to keep algebra simple.
  • Keep I/O deterministic; any extra reads/writes can corrupt reconstruction.
