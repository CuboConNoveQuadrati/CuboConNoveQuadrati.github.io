🔍 Step 1: Examining the ZIP Structure

Before extracting anything, I decided to take a closer look at the raw bytes of the ZIP file. This is a crucial step in forensic challenges, as the structure of the archive itself can reveal hidden information.

hexdump -C adofai.zip | head -50

While examining the hex dump, I noticed something peculiar: there appeared to be multiple entries with the same filename pattern. This suggested the ZIP file might contain duplicate files or overlapping entries.

💡 Key Discovery: The ZIP archive contained multiple flag.txt files! This is unusual because most archive tools will only extract the last occurrence of a duplicate filename, potentially hiding earlier versions.

📂 Step 2: Understanding ZIP File Duplicates

ZIP files can technically contain multiple entries with the same name. This happens when:

  • Files are added to an archive without proper deduplication
  • The archive is crafted intentionally to hide data
  • Multiple versions of the same file exist in the archive structure

Most extraction tools will only extract the last occurrence of a duplicate filename, which means earlier versions remain hidden unless you specifically look for them.

⚠️ The Challenge: One of these flag.txt files contained the real flag, while the others were decoys. I needed to extract and examine all of them.

🔧 Step 3: Using CyberChef for Extraction

Rather than wrestling with command-line tools that might only extract one version, I turned to CyberChef - a powerful web-based tool for data manipulation and forensic analysis.

CyberChef's "Unzip" operation can reveal all entries in a ZIP file, including duplicates, making it perfect for this scenario.

🔥 CyberChef Recipe:

  1. Load the adofai.zip file into CyberChef
  2. Apply the "Unzip" operation
  3. Set "Extract all files" to true
  4. Examine each extracted flag.txt entry

🔧 Technical Deep Dive

Understanding ZIP File Structure

ZIP files consist of three main sections:

  • Local file headers - Precede each compressed file
  • File data - The actual compressed content
  • Central directory - An index of all files at the end

When duplicate filenames exist, each has its own local file header and data section. Standard extraction tools typically read the central directory and extract based on the last occurrence, effectively hiding earlier duplicates.

Alternative Extraction Methods

Besides CyberChef, you could also extract all entries using:

# Python with zipfile library (accessing all entries)
python3 -c "import zipfile; z=zipfile.ZipFile('adofai.zip'); [print(i, z.read(i)) for i in z.namelist()]"
# 7zip with detailed listing
7z l -slt adofai.zip
