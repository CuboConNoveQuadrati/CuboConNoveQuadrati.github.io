file xoxo.png

🛠️ Analysis and Solution

🔍 Step 1: Automated Steganography Analysis

Rather than manually testing every steganography technique, I turned to Aperisolve - a powerful online tool that automatically runs multiple steganography detection methods on uploaded images.

💡 What is Aperisolve?

Aperisolve (https://www.aperisolve.com) is an automated steganography analysis platform that runs dozens of tools simultaneously, including:

  • zsteg - Detects LSB steganography in PNG and BMP files
  • steghide - Extracts embedded data from various formats
  • exiftool - Analyzes metadata
  • binwalk - Searches for embedded files
  • strings - Extracts readable text
  • And many more...

I uploaded xoxo.png to Aperisolve and waited for the automated analysis to complete.

The location was hidden in the least significant bits of the RGB channels!

🧩 Step 3: Understanding LSB Steganography

The zsteg tool revealed that data was hidden using LSB (Least Significant Bit) steganography. Let me break down what this means:

RGB Pixel Example: (Red: 11010110, Green: 10110011, Blue: 01101101)

LSB (rightmost bit): R=0, G=1, B=1

By modifying only the LSB of each color channel,
we can hide data while causing imperceptible changes
to the image (±1 color value per channel).

The specific notation b1,rgb,lsb,xy from zsteg means:

  • b1 - Using 1 bit per channel
  • rgb - Analyzing Red, Green, and Blue channels
  • lsb - Looking at Least Significant Bits
  • xy - Reading data in row-by-row order

🎨 Why LSB Works: Changing the last bit of a color value (e.g., 150 → 151) creates a difference invisible to the human eye, making it perfect for hiding data!

🔧 Technical Deep Dive

How LSB Steganography Works

Let's look at a practical example of hiding the letter 'P' (ASCII 80 = 01010000 in binary):

Original pixels (RGB values):
Pixel 1: (152, 145, 198) → Binary: (10011000, 10010001, 11000110)
Pixel 2: (201, 178, 233) → Binary: (11001001, 10110010, 11101001)
Pixel 3: (157, 143, 209) → Binary: (10011101, 10001111, 11010001)

Hide 'P' = 01010000 in LSBs:
Pixel 1: (152, 144, 199) → Changed LSBs to: 0, 1, 0
Pixel 2: (201, 178, 232) → Changed LSBs to: 1, 0, 0
Pixel 3: (156, 143, 208) → Changed LSBs to: 0, 0, (next char)

Visual difference: Imperceptible to human eye!
