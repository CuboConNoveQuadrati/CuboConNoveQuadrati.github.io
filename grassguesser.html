📝 Challenge Description

Who cares about geoguesser, we have grass guesser now

🌐 Webpage: http://23ce1851.ctf.ac.upt.ro

🔎 Initial Reconnaissance

Upon visiting the web application, I was greeted with a geographic guessing game - similar to GeoGuessr but with a twist. The challenge required me to correctly identify the coordinates of 10 different locations in a row.

curl -X POST http://23ce1851.ctf.ac.upt.ro/api/start
{"sessionId":"56de5eff813cb637aeb95756e4966e39","totalRounds":10}

The game mechanics were straightforward but brutal:

  • 🎯 Guess the correct coordinates for 10 different locations
  • 📍 Each guess returns the distance from the target location
  • ❌ One wrong guess resets the entire game back to location #1
  • ✅ Only after correctly guessing all 10 locations would the flag be revealed

⚠️ The Challenge: The brutal reset mechanism made manual solving impractical. However, I noticed something crucial - even when the game reset, the target coordinates remained the same!

🛠️ Analysis and Solution

🧩 Step 1: Understanding the Game Mechanics

I started by analyzing the API endpoints to understand how the game worked:

POST /api/start → Returns sessionId
POST /api/guess → {sessionId, lat, lng} → Returns {correct, distance, gameWon, flag?}

The key observations were:

  • Each session maintains state about which coordinates have been found
  • The API returns distance information when a guess is incorrect
  • Coordinates persist across game resets within the same challenge instance
  • The flag is only revealed after correctly identifying all 10 coordinates consecutively

💡 Critical Discovery: The coordinates don't change between attempts! This means I could build a database of correct coordinates and reuse them across multiple game sessions.

🎯 Step 2: Developing the Strategy

With the coordinate persistence insight, I devised a multi-stage approach:

  1. Coordinate Storage: Maintain a list of all successfully found coordinates
  2. Progressive Discovery: Use gradient descent to find new coordinates
  3. Session Management: Submit known coordinates first to advance through checkpoints quickly
  4. Intelligent Search: Implement a hill-climbing algorithm to minimize distance iteratively

The beauty of this approach is that each failed attempt teaches us at least one new coordinate, making subsequent attempts progressively easier.

🎲 Algorithm Overview

The solver implements a sophisticated multi-phase search strategy:

Phase 1 - Checkpoint Replay: Submit all previously discovered coordinates to quickly advance to unknown locations.

Phase 2 - Gradient Descent Search: Use distance feedback to navigate toward the target using directional steps (North, South, East, West, and diagonals).

Phase 3 - Adaptive Step Sizing: Start with large steps (10°) and progressively reduce when stuck, allowing both coarse and fine-grained searching.

Phase 4 - Random Restart: If completely stuck, try a new random starting position to escape local minima.

💻 Complete Solution Script

import requests
import random

s = requests.Session()
URL = "http://da0d1111.ctf.ac.upt.ro/"

# Database of known correct coordinates
right_coords = [
    (51.50739578092163, -0.12784588661043017),   # London
    (48.856566708021376, 2.3522047289735184),     # Paris
    (40.78284731725431, -73.96543803155782),      # New York
    (-33.868750193977505, 151.209236818929),      # Sydney
    (35.67629475790484, 139.65029812360805),      # Tokyo
    (52.520026967973905, 13.40494624044885),      # Berlin
    (41.89027541139387, 12.492252417804764),      # Rome
    (37.77487697786999, -122.4193696846143),      # San Francisco
    (55.75575886842542, 37.61729552503313),       # Moscow
    (1.2896523082792868, 103.85004511632928)      # Singapore
]

# Start the game
r = s.post(URL+"api/start")
sessionId = r.json()['sessionId']

def find_coordinate():
    """
    Finds a single coordinate using gradient descent with adaptive step sizing.
    Returns True if successful, False otherwise.
    """
    # Submit all known coordinates first to advance checkpoints
    for coord in right_coords:
        r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': coord[0], 'lng': coord[1]})
        if r.json()['gameWon']:
            print("Flag:", r.json()['flag'])
            exit(0)

    # Start with a random coordinate for exploration
    lat = random.uniform(-80, 80)
    lng = random.uniform(-170, 170)
    
    # Get initial distance feedback
    r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': lat, 'lng': lng})
    response = r.json()
    
    if response.get('correct'):
        right_coords.append((lat, lng))
        print(f"Found coordinate: ({lat}, {lng})")
        return True
    elif response.get('gameWon'):
        print(response['message'])
        return True
    
    distance = response['distance']
    step_size = 10.0  # Start with large steps for coarse search
    
    for attempt in range(200):  # Maximum attempts per coordinate
        # Try moving in 8 directions
        directions = [
            (lat + step_size, lng),                      # North
            (lat - step_size, lng),                      # South  
            (lat, lng + step_size),                      # East
            (lat, lng - step_size),                      # West
            (lat + step_size/2, lng + step_size/2),      # Northeast
            (lat + step_size/2, lng - step_size/2),      # Southeast
            (lat - step_size/2, lng + step_size/2),      # Northwest
            (lat - step_size/2, lng - step_size/2),      # Southwest
        ]
        
        best_lat, best_lng = lat, lng
        best_distance = distance
        found_better = False
        
        # Evaluate all directions to find the best move
        for new_lat, new_lng in directions:
            # Validate geographic bounds
            if -90 <= new_lat <= 90 and -180 <= new_lng <= 180:
                # Re-submit checkpoints before testing new position
                for coord in right_coords:
                    s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': coord[0], 'lng': coord[1]})
                
                r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': new_lat, 'lng': new_lng})
                response = r.json()
                
                if response.get('correct'):
                    right_coords.append((new_lat, new_lng))
                    print(f"Found coordinate: ({new_lat}, {new_lng})")
                    return True
                elif response.get('gameWon'):
                    print(response['message'])
                    return True
                
                new_distance = response['distance']
                
                # Track the best direction
                if new_distance < best_distance:
                    best_distance = new_distance
                    best_lat, best_lng = new_lat, new_lng
                    found_better = True
        
        # Move to the best position found
        if found_better:
            lat, lng = best_lat, best_lng
            distance = best_distance
        else:
            # No improvement found - reduce step size for finer search
            step_size /= 2
            
            if step_size < 0.0001:  # Very close to target
                # Try micro-adjustments
                fine_steps = [
                    (lat + 0.0001, lng), (lat - 0.0001, lng),
                    (lat, lng + 0.0001), (lat, lng - 0.0001)
                ]
                
                for new_lat, new_lng in fine_steps:
                    if -90 <= new_lat <= 90 and -180 <= new_lng <= 180:
                        for coord in right_coords:
                            r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': coord[0], 'lng': coord[1]})
                            if r.json()['gameWon']:
                                print("Flag:", r.json()['flag'])
                                exit(0)                        
                        
                        r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': new_lat, 'lng': new_lng})
                        response = r.json()
                        
                        if response.get('correct'):
                            right_coords.append((new_lat, new_lng))
                            print(f"Found coordinate: ({new_lat}, {new_lng})")
                            return True
                        elif response.get('gameWon'):
                            print(response['message'])
                            return True
                        
                        new_distance = response['distance']
                        if new_distance < distance:
                            lat, lng, distance = new_lat, new_lng, new_distance
                            break
                else:
                    # Stuck in local minimum - random restart
                    lat = random.uniform(-80, 80)
                    lng = random.uniform(-170, 170)
                    step_size = 10.0
                    
                    for coord in right_coords:
                        s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': coord[0], 'lng': coord[1]})
                    
                    r = s.post(URL+"api/guess", json={'sessionId': sessionId, 'lat': lat, 'lng': lng})
                    response = r.json()
                    
                    if response.get('correct'):
                        right_coords.append((lat, lng))
                        print(f"Found coordinate: ({lat}, {lng})")
                        return True
                    elif response.get('gameWon'):
                        print(response['message'])
                        return True
                    
                    distance = response['distance']
        
        # Progress logging
        if attempt % 20 == 0:
            print(f"Attempt {attempt}, distance: {distance:.2f}km, pos: ({lat:.4f}, {lng:.4f})")

# Main execution loop
for i in range(10):
    print(f"\n{'='*60}")
    print(f"Finding coordinate {i+1}/10...")
    print(f"{'='*60}")
    success = find_coordinate()
    if not success:
        print(f"❌ Failed to find coordinate {i+1}")
        break
    print(f"✅ Successfully found {len(right_coords)} coordinates")

print("\n🎯 All found coordinates:", right_coords)

🧠 How the Algorithm Works

1. Submit known coordinates → Advance to unknown checkpoint
2. Random starting point → Get initial distance
3. Test 8 directions → Find direction that reduces distance
4. Move in best direction → Update position
5. If stuck → Reduce step size (10° → 5° → 2.5° → ...)
6. If very stuck → Random restart to escape local minimum
7. Repeat until distance ≈ 0 → Coordinate found!

🔧 Technical Deep Dive

The Hill Climbing Algorithm

The core of the solution uses a variant of the hill climbing algorithm with these enhancements:

f(position) = distance_to_target
goal: minimize f(position)

while not at target:
  evaluate all neighboring positions
  move to position with smallest distance
  if no improvement: reduce step_size
  if completely stuck: random_restart()

Why This Works

The challenge's distance feedback creates a convex optimization landscape where we can reliably converge to the target:

  • Single Global Minimum: Distance has only one minimum (the target coordinate)
  • Monotonic Improvement: Moving toward the target always reduces distance
  • No Local Minima: Unlike many optimization problems, geographic distance has no false peaks

Optimization Considerations

The script could be further optimized by:

  • Using binary search on step sizes instead of linear reduction
  • Implementing parallel exploration of multiple starting positions
  • Leveraging spherical geometry for more accurate distance calculations
  • Caching API responses to reduce redundant requests
